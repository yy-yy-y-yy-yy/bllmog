# ベイフォータス（ニルセビマブ）— ラベルは広く、扉は狭い

承認版・日本発売済み。

## 1. 入口の場面

2024年2月19日、PMDA の審査報告(2) に、企業側のミスがそのまま書き留められた。世界に先駆けて正確な補充投与基準が東京で確定した、という静かな勝利のはずだった。

同じ報告書の少し前の段落に、もっと重い一行がある。「ビジネス上の理由により、申請者内での両申請の情報共有には厳格な制限がかけられた結果、同様の審査内容に関する対応に一部乖離が見られ」、機構は「必要な情報共有体制を構築すべきであった」と考えた 。審査中に申請者（アストラゼネカ）が**パリビズマブの一部変更申請（2023-06-30）**という別動線を走らせていたこと、その二つの申請の間に社内の防火墙が張られていたこと — 当局が企業の統治構造そのものを批判として記録するのは稀だ 。

ラベル（適応）史上最も広く設計された RSV 予防薬の日本での決着は、用量の正しさと、社内情報流通の誤りという、対照的な二つの記述で刻まれた。

## 2. 物質と権利

ニルセビマブは、RSV フュージョン蛋白の立体構造エピトープ（F2/F1）に結合するヒト B 細胞由来抗体 D25 に、**半減期延長の YTE 変異**を組み込んだ単クローン抗体で、CHO 細胞で産生される 。1 回筋注で流行期（約 5 か月）を覆う「受動免疫」であり、ワクチンでも抗ウイルス薬でもない。開発コードは D5290C0000x シリーズ 。

権利の地図は三方に割れている。日本での**申請者はアストラゼネカ株式会社**、**製造販売業者はサノフィ株式会社**（2025 年前半に AZ から承継。RMP に「承継に伴う製造販売会社の変更」「特定使用成績調査実施計画書の承継」と明記される）。米国の BLA 761328 のスポンサーは ASTRAZENECA AB 。そして Sanofi の決算には「**推定将来 Beyfortus 米国売上に対するロイヤルティ**」という金融負債が載り、相手先名はどの開示文書にも現れない 。物質は一つ、帳簿の上で売上・製造・ロイヤルティが別々の会社を流れる。

## 3. 意思決定年表（語りの本文）

### 3.1 2019–2021：勝てる主評価、勝てない二次

Ph2b（全員 50mg 固定用量）で RRR 70.1%［52.3, 81.2］を得た開発チームは、2019-07-23 に MELODY を開始する。正期産・後期早産児 3,012 例、体重で 50/100mg を分ける二段用量 。MELODY は主評価に勝った — MA RSV LRTI で 12/994 vs 25/496、**RRR 74.53%［49.63, 87.12］、p<0.0001**（pre-specified）［]。しかし同じ試験の**入院**（pre-specified 二次）は、ラベルに載った時点で **60.2%（95%CI −14.6, 86.2; p=0.09）** と、信頼区間が 0 を跨いだままだった [ §14.3]。「RSV 入院を防ぐ」という最大の売り文句は、この時点の RCT では**証明されていない**。

2021-03-11、MELODY は完了する。結果は公開されなかった。ClinicalTrials.gov への Posting は **2024-02-28** — 完了から約 2 年 11 か月後、**日本承認の 4 週間前**である 。

### 3.2 2022：欧州が最初の扉を開ける

2022-09-16、CHMP が承認を推奨し、アストラゼネカは PR で「もし承認されれば、これが**最も広範な新生児・乳児集団に対する初の予防選択肢**になる」と書いた 。10-31 に EC 承認（SmPC「authorised 31 October 2022」）。Sanofi は 10-28 の決算 PR で、対象を「健康な児、正期産児、早産児、**特定の健康問題を持つ児**」と明記し、「単回投与の受動免疫」というカテゴリそのものを発明したかのように語り始める 。

### 3.3 2023：米国承認と、日本の二枚仕度

米国では AMDAC がベネフィット・リスク有利で**全会一致**（結果の重篤度を決める諮問段階を通過。会期日付は一次資料に明記がなく未確認）、2023-07-17 に FDA 承認（STANDARD 審査）［]。適応は初回流行期の全新生児・乳児＋「24 か月齢以下で重症 RSV に脆弱な児」の第 2 流行期 。添付文書には s005（2024-08-22）・s012（2025-10-20）と **EFFICACY 型の補充承認**が積み上がり、承認後の有効性表示拡張が続く 。

日本で申請（2023-02-28）した申請者は、二枚仕度を組む。一枚目は**適応の広さ**：重症化リスク因子児は初回・2 回目流行期、それ以外の全新生児・乳児は初回流行期 — 米欧を組み合わせたような二層ラベル 。二枚目は**償還の狭さ**：審査報告書は「申請者は本剤の申請効能・効果に含まれる重症化リスク因子を含む適応で**パリビズマブの製造販売承認事項一部変更承認申請（2023-06-30）**を行った」と記し、加えて後期早産児・正期産児を**保険償還範囲外**とする計画を機構が把握していたことが読み取れる記載がある 。広いラベルで臨床現場を確保し、狭い償還で財源と既存品（パリビズマブ）の席を守る — 入口を二重に設計した。

### 3.4 2024：東京での 57 日と、数字の三重のズレ

審議 2024-03-04、承認 2024-03-26、**薬価収載・発売 2024-05-22** 。承認から発売まで 57 日。承認前の 2024-02-28 には MELODY が Posting され、そこに**日本人集団の post-hoc 解析が RRR −56.8%［−1,295.8, 82.4］（3/33 vs 1/17）**という、点推定が負の方向を向く小さな表が乗っていた 。審査を通過した適応の土台は、日本人集団では統計的に何も語らない — 適応の正当性は日本人データではなく、グローバル主評価＋流行期の生物学的必然（YTE 半減期）に依拠していた 。

同年、数字の複製劣化も進む。主評価は CTG が 74.53%、アストラゼネカ PR が 74.9%［50.6, 87.3］、PMDA 審査報告が 74.5% 。そして HARMONIE 相当試験（NCT05437510、無介入対照・オープンラベル、8,057 例）の主評価は、**CTG に 11/4038 vs 64/4019 → 84.04%［69.49, 92.41］、米欧ラベルに 11/4037 vs 60/4021 → 83.2%（67.8, 92.0）**と、イベント数から分母から効果量まで違う二つの版が同時に存在する [ §14.5]。

### 3.5 2025–2026：RWD の春、決算書の秋

製造販売業者が AZ からサノフィへ調査義務ごと承継され（2025-06-27 変更、08-01 提出）［]、特定使用成績調査（1,000 例・観察 150 日・免疫不全＋ダウン症候群 ≥300 例）が始動する（2025-03〜）［]。供給 PR は「生産能力 3 倍・製造拠点 2 倍・40 研究 25 万人」（2025-06-09）。Lancet ID に載った NIRSE-GAL は、初回期に接種した児の**第 2 流行期**入院まで −55.3%［22.5, 74.3］と報告した（観察研究）［]。

決算書は別の季節を映す。FY2025 Beyfortus €1,781M（+9.5%）も、Q4 の米国は **−31.9%**、2026Q1 は −21.5% で要因欄に「**competition**」の語が現れる 。競合は仕様の急所を突いてきた — Merck の ENFLONSIA（clesrovimab）は「**体重にかかわらず同一用量**」を旗印に 2025 年夏 FDA 承認＋ACIP 推奨、2026-04 EC 承認、**2026 年夏に日本・中国承認** [–]。ニルセビマブの 50/100mg 体重分割設計は、競合のパンフレットで初めて「設計上の選択」として可視化された。2026 上半期、Sanofi は Beyfortus 関連無形資産 **€59M を減損**し、米国売上ロイヤルティ負債の再測定で **€146M の金融収益**を計上した（FY24 −€291M → FY25 +€93M に続く符号反転）［]。将来売上の期待値が、損益計算書の符号として決算に現れ続ける薬剤になった。

## 4. 失敗／緊張の解剖（六層）

- **有効性層**: 主評価は強固。ただし入院エンドポイントは RCT で未証明（0-cross）のまま市場言説が先行。**致命的層（換金側）**。
- **安全性層**: 重要な特定されたリスク「該当なし」。過敏症 21 例（大半 G1-2）・血小板減少 1 例、いずれも潜在的リスク枠 。この薬で安全性はボトルネックにならなかった。
- **試験設計層**: 二つ。「有効性外挿」に依存した MEDLEY（主評価＝安全性）と、無介入対照・オープンラベルの HARMONIE 相当 — 対照の強度を落として有効性の一般化を買いにいく設計が後年、競合との比較語彙で不利に働く。
- **試験遂行層**: MELODY の「試験中断」脚注（目標 3,000→主解析約 1,500）と Posting 約 3 年遅延 。理由は今も公式に不明。
- **規制層**: 日本は是正機能として機能した（CPB 基準の転記誤り検出）。同時に、ラベルと償還の乖離を当局が文書化しつつ、その着地（中医協）は公開文書から追えない 。
- **事業層**: **致命的層はここ**。広い適応・速い発売（57 日）・供給増強にも関わらず、①償還範囲を自ら削ったこと、②体重分割という用量設計が競合に同一用量攻撃の材料を与えたこと、③減損とロイヤルティ符号反転に象徴される期待修正が、2 年以内に三重に着地した 。

## 5. 四チームの視点

**開発**：当時の手 — MELODY 完了後に結果を公開し、入院サブエンドの 0-cross を早期に認めて二次エンドポイントを再設計する（入院を主評価に置く別試験、または事前宣言の階層検査）。反証条件 — 入院サブエンドが事前宣言で十分検出力を持っていたなら、3 年遅れの Posting 自体が誤りでなく単なる事務だったことになる。
**薬事**：当時の手 — 二層適応＋償還縮小の非対称設計を、審査開始前に一つの「入口戦略」として統合し、パリビズマブ一部変更申請との整合を社内で担保する（機構が指摘した「乖離」を未然に潰す）。反証条件 — 二つの申請が本来別事業部管轄で統合不能なら、機構批判は制度側の想定範囲内だったことになる。
**メディカルアフェアーズ**：当時の手 — RCT で証明できない「入院」主張を RWD に移す際、MELODY の「試験中断」脚注と日本人 post-hoc の負の点推定を、資料の一次脚注として自前で公開する誠実さを見せる。反証条件 — HARMONIE 相当の三重の数値ズレ（CTG vs ラベル）が単なる転記管理の失敗でなく解析改定史として説明できるなら、RWD 移行は「逃げ」でなく「昇格」だったと証明される。
**事業**：当時の手 — 発売直後 2 年の「競合不在の窓」で、体重分割の運用コスト（2 本 SKU・体重確認）を売る前に引き受ける（体重無差別投与の臨床データを自ら作り、「5kg 閾値」を自社の落とし穴にしない）。反証条件 — ACIP/中医協が実装ゲートとして機能せず価格競争のみなら、設計の急所ではなく価格が負けたことになる。

## 6. 時代の環境

2022–2024 は受動免疫というカテゴリの立ち上げ期（CHMP 推奨 2022-09-16 、ACIP 推奨が実装ゲート化する米国の構造）、2025–2026 は競合揃い期（ENFLONSIA の米欧日承認 2025–2026 [–]、耐性回避を仕様に埋め込む次世代 VBY329 の登場 2025-11-24）だった。

## 7. 答えのない質問

1. **「償還範囲を削ったのは失敗か、それとも唯一の通し方だったか」**。(a) 肯定（設計として合理）: 審査報告書が申請者計画として記載を許容＝当局と摩擦なく承認 57 日発売に至った 。(b) 否定: 削った層（後期早産児・正期産児）はそのまま 2026 年に競合の同一用量設計が拾う市場だった 。(c) 決着に必要な観測: 中医協資料での償還範囲の最終形と、収載後の実使用内訳（層別数量）。(d) 関連: パイプライン編 aducanumab（償還の門）、パイプライン編「入口設計」軸。
2. **「MELODY はなぜ 3 年間 Posting されなかったのか」**。(a) 「中断」脚注が公式な理由 。(b) 一方で Posting 2024-02-28 は日本承認 4 週前という戦略的タイミングと読める 。(c) 決着に必要な観測: CTG の履歴変更ログ、または審査報告書外資料での中止理由。(d) 関連: 台帳全体の「登録 vs 公表の差」列。
3. **「入院を防げるという主張は、いつから正当だったのか」**。(a) 2024-10 のメーカー集計「80% 超」。(b) RCT 二次は 0-cross 、無介入対照の Ph3b はオープンラベル 。(c) 決着に必要な観測: 事前宣言済みの入院主評価 RCT、または介入設計の前向きリアルワールド。(d) 関連: efgartigimod（承認後の有効性拡張の実務）。
4. **「ロイヤルティ相手先は誰で、何を取り決めたのか」**。(a) Sanofi が負債として認めている 。(b) 20-F にも四半期 PR にも名称なし、AbbVie 関連開示は EDGAR に 0 件。(c) 決着に必要な観測: 相手先側の決算注記、または契約開示付き有価証券届出。(d) 関連: 「物質は一つ、帳簿は三つ」の権利解剖シリーズ（aducanumab の BI 移行と対比）。

## 8. 教訓（開発者向け）

1. ラベルは最大の許容範囲、償還は最小の約束 — 二つを同時に設計しない薬は、発売後の 2 年で競合に隙間を売ることになる。
2. 二次エンドポイントの信頼区間が 0 を跨いだまま営業言語が先に進んだら、その薬の証拠台帳は永遠に「80% 超」と「−14.6, 86.2」の両方を持つことになる。
3. 用量設計の「正しさ」（体重分割）は、競合が来ない間だけ透明である — 競合が来ると、それは仕様書の弱点として引用される。
4. 申請者内の防火墙は、審査報告書という永久保存文書に「乖離」と記録される。
5. ロイヤルティ負債の再測定符号（−291M→+93M→+146M）は、事業部が認めない期待下方修正を決算書が先に認める装置になる。

## 時代の環境

### 1. 資金・事業文脈（決算での本剤言及）

- Sanofi 決算での Beyfortus 開示時系列（Vaccines フランチャイズ、販売は Sanofi）: FY2025 **€1,781M（CER +9.5%）**／Q4 €686M（−14.9%、米国 −31.9%・欧州 −24.5%＝前期在庫高ベース、ROW +105.8%）［2026-01-29 PR］→ 2026Q1 €284M（+2.8%、米国 −21.5%＋「competition」）［2026-04-23］→ 2026Q2 €108M（+54.2%、南半球需要）［2026-07-30］。
- 同じ決算書の同ページに「**Beyfortus 関連無形資産 €59M の減損**」（Ayvakit €295M、Bioverativ €285M、Tzield €100M、Ablynx €82M、Rezurock €76M と並ぶ 2026H1 減損群）。
- **米国売上ロイヤルティ負債**（相手先不明）: FY2024 再測定 −€291M 費用 → FY2025 +€93M 収益 → 2026H1 +€146M 収益。売上期待の下方修正が「金融収益」として現れる構造。
- Merck 側: ENFLONSIA を 2025 年末「US launch」、2026 年 EC 承認（4 月）→ 日本・中国承認（2026 夏）と四半期決算で列挙。
- Invivyd（小規模バイオ）: VBY329 を「2024 年 blockbuster 市場、**年間 $3–4B へ成長見込み**」の小児 RSV 予防市場への参入と位置づけ（2025-11-24）。

### 2. 規制環境の変更

- 米国: CDC/ACIP が**推奨という別ゲート**で用量・月齢を設計する（ENFLONSIA には「<8 か月児の初回流行期」推奨が 2025 年夏に着く）。FDA 承認 ≠ 実装範囲。
- 日本: 適応（ラベル）と**保険償還範囲が分離**されていることを当局文書が明記（「後期早産児・正期産児を償還範囲外とする申請者考」審査報告書）。中医協での着地は未確認。
- 制度道具: 特定使用成績調査（1,000 例・150 日）＝**承認条件として希層（免疫不全・ダウン症候群）の有効性検証を製造販売後に外注する**設計。
- EU: SmPC 主評価の入院リスク比は CI が 0 を跨ぐ（62.1%、−8.6〜86.8）＝**入院防止を数値的に約束しないラベル**が欧米共通の地層。

### 3. メディア・社会運動

- 本件で確認できた独立メディア見出しは**なし**（取得したのは会社 PR と当局文書のみ）。会社側 PR 見出しの系譜: 「EU で承認推奨」（AZ 2022-09-16）→「米国で承認、初の広範乳児対象予防」（AZ 2023-07-17）→「実効性 80% 超、一貫」（Sanofi 2024-10-09）→「生産能力 3 倍・40 研究 25 万人」（Sanofi 2025-06-09）→「45 か国以上」（2026-01/04/07）→「第 2 シーズンまで受益」（2026-02-16）。**主張が「承認→実効性→供給→波及効果」へ段階的に格上げ**される系列として読める。
- 独立報道・患者運動の材料未取得。

### 4. 学術的論争（提唱と反論）

- 「受動免疫でRSV入院を防げるか」: MELODY 主評価（pre-specified、74.53［49.63, 87.12］）は確立。一方**入院サブエンドポイントは RCT では 0 を跨ぎ未証明**（60.2%、−14.6〜86.2、p=0.09）→「入院を防ぐ」主張は RCT ではなく **HARMONIE 相当 Ph3b（無介入対照・オープンラベル）**とリアルワールド（NIRSE-GAL、−85% 級＋第 2 シーズン −55.3%）に依存。反論側材料: 無介入対照のオープンラベル設計はバイアス方向に開いている／MELODY に「試験中断」脚注（理由未公開）。
- 「耐性は育つか」: Invivyd が「ニルセビマブ耐性変異」を実測材料として商品仕様書に使う段階に到達（2025-11）。反論（耐性の臨床的意義を示す疫学データ）は未取得。

### 5. 同機序・隣接競争（生死）

- **生死が確定した競争**: clesrovimab（Merck/ENFLONSIA）— 2025-02 BLA 受理 → PDUFA 2025-06-10 → 2025 夏 FDA 承認＋ACIP 推奨 → 2026-04 EC → **2026 夏・日本/中国承認**［–］。差別化の突き方が「**体重によらず同一用量**」＝ニルセビマブの 50/100mg 体重分割設計への直接反証攻撃。
- 隣接: 母体ワクチン（Abrysvo）の日本状況は PMDA 検索ヒットなし＝未確認。親会社決算に nexavimab の痕跡なし（EDGAR 0 件）。
- 次世代: Invivyd VBY329（耐性回避＋高効力＋長半減期を標榜、2H2026 に IND 準備）。

### 6. 追い風／向かい風の総括

- 追い風（2022–2024）: 承認前例ゼロの「広範乳児」市場、CHMP/AMDAC の全会一致級支持、日本では**世界最広の適応二層**、供給増強（3 倍・2 倍）、各国プログラムの初年 RWD「80% 超」。
- 向かい風（2025–2026）: 高ベース後の**米欧の反動減**（Q4 米 −31.9%）、ACIP 実装が競合に推奨を与える構造（2025 夏）、**競合の同一用量設計**、無形資産減損 €59M とロイヤルティ負債の符号反転（期待修正）、日本でも 2026 年に競合参入。
- 非対称: 向かい風は**売上側**に集中し、**臨床証拠側**（第 2 シーズン効果の観察的確認・安全性プロファイル安定期）はむしろ改善した。

### 7. 「そのとき、そのチームは何を見ていたか」

- 開発（2021-03、MELODY 完了時）: 主評価は勝っている。負けているのは**有意でない二次（入院）**と、まだ誰も見ていない Posting 遅延（自社登録の公開は 2024-02-28、承認 4 週前）。「待つ」を選んだ。
- 薬事（2023-02–2024-02、日本）: EU 承認済・米審査中という差分。選んだのは**二層適応**（リスク因子児＝2 期＋それ以外＝初回期）と、償還側は**削る**（後期早産児・正期産児を保険償還範囲外とする申請者計画）という**ラベルと償還の非対称設計**。
- メディカルアフェアーズ（2024–2026）: RCT で証明できなかった「入院」を RWD（NIRSE-GAL 等）と国際会議（IDWeek 2024）で語る役割が明確化。
- 事業（2024-05〜）: 発売直後から供給（3 倍・2 倍）と展開（45 か国）を語り、2026 年には「competition」を四半期 PR に書き込む側へ転じる。

### C. 有効性（pre-specified / post-hoc の別を全件付記）

- MELODY 主評価（**pre-specified**）: MA RSV LRTI（投与後 150 日）12/994 vs 25/496、**RRR 74.53%［95%CI 49.63, 87.12］、p<0.0001**。会社 PR は「74.9%（95%CI 50.6, 87.3; P≤0.001）、イベント率 1.2% vs 5%」と表記、PMDA 審査報告は「74.5［49.6, 87.1］」。**同一エンドポイントの三表記ゆれ**。
- MELODY 入院（**pre-specified 二次**）: 米ラベル **60.2%（95%CI −14.6, 86.2; p=0.09）**、EU SmPC **62.1%（−8.6, 86.8）**。**いずれも CI が 0 を跨ぎ統計的優位なし**（会社 PR は二次の有意性を主張せず）。
- MELODY 日本人集団（**post-hoc/探索、少数**）: RRR **−56.8%［−1,295.8, 82.4］**（3/33 vs 1/17）。点推定が負（見かけ上不利）でありながら CI が極端に広い。**日本適応の根拠はこの集団単独では成立しない**。
- MELODY 中止記載: 審査報告書脚注に目標 3,000 例→主解析コホート約 1,500 例で「**試験中断**」の記載あり。中止理由は審査報告書本文に記載なし（§J）。
- Ph2b（pre-specified）: RRR 70.1%［52.3, 81.2］（46 vs 25）。本試験は**全員 50mg 固定用量**（体重階層なし）で、日本 IF 脚注はこの試験を低用量設計の参照として引用。
- MEDLEY: 主評価は安全性のみ。有効性は「**外挿（extrapolation）**により確立」とラベル明記。第1流行期 MA RSV LRTI 4/616（0.6%）vs パリビズマブ 3/309（1.0%）。第2流行期（CLD/CHD、200mg 追加投与コホート）は**イベント 0 例**（有効性評価不能）。

### D. 安全性

- 過敏症: 臨床試験全体（Ph2b/MELODY/MEDLEY/MUSIC）で**ニルセビマブ関連と判断された過敏症関連事象 21 例**（斑状丘疹状皮疹 9、発疹 8 など。大半 G1-2。重篤事象で因果関係ありはなし）。RMP は**重篤な過敏症反応＝重要な潜在的リスク**（他の IgG1 mAb でアナフィラキシー報告あり）。ラベル §5.1 に過敏症・アナフィラキシー警告。
- 血小板減少: 関連事象**1 例（点状出血、G1）**のみ。RMP は「本剤による血小板減少を示唆する証拠はない」が**類薬（パリビズマブ等）の副作用として注意喚起されている**ことを根拠に重要な潜在的リスク化。
- 重要な特定されたリスク: **該当なし**。重要な不足情報: **該当なし**（有効性の検討事項は §C の免疫不全/ダウン症候群）。
