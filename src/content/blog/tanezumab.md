# 委員会は1対19で否決した。しかし死亡診断書を書いたのは、6か月後の会社自身だった

### tanezumab（RN624 / PF-04383119 / EU名 Raylumis）— 「非オピオイドの夢」は有効性では負けていない。関節破壊に対して入口設計（REMS）が敗れ、米・EU・日本の3申請は同時に畳まれた

* 情報参照日 2026-09-02。**tanezumab はどの国でも承認されていない**（米 openFDA に申請記録なし）。本稿の記述は FDA ブリーフィング文書・合同委員会議事録/トランスクリプト（BLA 761130、2021-03-24/25）、Pfizer の 10-Q（2021 年 Q2・Q3）、EMA の Summary of opinion（Raylumis 拒否、2021-09-16）、ClinicalTrials.gov の登録と Posting、査読論文（Pain 2021・Pain Manag 2022・Arthritis Rheum 2013）にもとづく。「当時の声」は媒体名・日付付きの二次資料。本稿はいかなる医療行為・薬剤使用の推奨でもない。*

## 1 票は、有効性にではなく「入口」に投じられた

2021年3月25日、FDA の関節炎諮問委員会と医薬品安全性・リスク管理諮問委員会の合同会合で、議長がこう読み上げた——「**we have 1 yes, 19 no, and zero abstentions**」。投票の質問は「tanezumab は痛みを取るか」ではなかった。議事録に記録された質問はこれだ:

> 「申請者が提案した REMS は、tanezumab のベネフィットがリスクを上回ることを**保証できるか**？」

Yes 1 / No 19 / Abstain 0。**委員会は FDA ではない**（本シリーズの規律）。その約6か月後、FDA は Complete Response Letter を出し、2021年9月16日には EMA の CHMP が承認拒否の否定意見を出し、そして 2021年10月、**Pfizer と Eli Lilly は自らの決算文書にこう書いた**:

> 「**2021年10月、Pfizer と Lilly は tanezumab のグローバル臨床開発プログラムを中止した**。……本決定は、（中略）FDA からの Complete Response Letter の受領と、EMA ヒト用医薬品委員会（CHMP）の否定意見の採択に**引き続いて**なされた」

「誰が最後まで推し、誰がとどめを刺したか」という問い against この分子は、三つの答えを持つ。推し続けたのは、2010年にクラスごと凍結された後も 2013年に賭けを continuation した二社（Pfizer と、この年に参入した Lilly）。票を投じたのは二つの諮問委員会（1-19）。そして死亡診断書を書いたのは、CRL と CHMP 意見を受けた**両社自身**だった——同じ月に、グローバルで、がん疼痛プログラムごと。

そしてほとんど誰も覚えていない事実として、**日本はこの列車に一番最後に乗っていた**。Pfizer の 2021年7月時点の申請状況表には、tanezumab の行が三つ並んでいる——Filed March 2020（米国）、Filed March 2020（EU）、**Filed Aug. 2020（日本）**。三地域申請が、7か月以内に全部死んだ。

## 2 物質と権利 — Rinat が作り、Pfizer が買い、Lilly が疑義中に賭けた

tanezumab（旧コード RN624、Pfizer 治験成分コード PF-04383119）は、**神経成長因子（NGF）を標的とするヒト化モノクローナル抗体**である。痛みを「受容体の下流で遮る」のではなく、痛みそのものの発生に絡む神経栄養因子を封じる——2000年代としては最も野心的な非オピオイド鎮痛戦略だった。創製は Rinat Neuroscience、2006年に Pfizer が買収した（金額は本稿で一次未取得＝**未確認**）。2004年に IND（11680）が開設され、2008年11月に約5,000例計画の OA フェーズ3プログラムが始まった。

権利のもう一本の線は 2013年に引かれた。**hold とクラス疑義の最中**に、Pfizer は Eli Lilly と提携した（米国共同商用化・米国以外 Pfizer。契約原文は未取得＝**未確認**）。ClinicalTrials.gov の lead sponsor は全期間 **Pfizer** のまま。規制申請者は米国 BLA 761130＝Pfizer、EU＝Pfizer Europe MA EEIG。日本提出主体は開示表から区別できない（**未確認**）。

## 4 失敗の解剖 — 六層（そして致命的層は二つ重なっている）

**有効性層。** ここは**壊れていない**——そしてこれが本件最も誤解されている点だ。FDA 自身の結論表にこう書いてある: 「統計的な有効性の実質的証拠（substantial evidence）を満たしたか？ → **2 つの適切な対照試験が、tanezumab 2.5 mg が OA 痛でプラセボに優越することを示している**」。ただし同時に FDA はこうも書いた: 「NSAIDs と比べてどうか？ → **以前に処方強度の NSAIDs に失効した患者で、naproxen、celecoxib、diclofenac に優越しない**」。16週の痛の差は -0.6 点、24週で -0.5 点、52週の試験（1058）では 2.5 mg が共主要3項目すべてに敗北。「効く」は証明された。「より良い」は証明できなかった。

**安全性層。** 致命傷はここにある。複合関節安全イベント（CJSE）の発生は、1056/1057 で **placebo 群 0／tanezumab 2.5 mg 2.4／5 mg 4.6（100人年）**、1058 では NSAIDs 比 **ハザード比 2.6（2.5 mg）・5.0（5 mg）**、そして**用量依存的**。急速進行性 OA（RPOA）は Type 1（1年で関節裂隙 ≥2 mm 狭小）・Type 2（骨の破壊・崩壊）に定義され、**RPOA2 の 60%・RPOA1 の 15% が関節全置換（TJR）に至り、RPOA2 で薬を中止しても進行は止まらない**。さらに RPOA は**画像上健康な関節（KL grade 0-1）でも**起きた。

**試験設計層。** 共主要（痛・身体機能・患者グローバル評価）は 16 週では勝って 52 週で壊れた。患者選抜（既存薬失効歴）のスクリーニング文書は「poorly documented」とされたが、FDA は post-hoc で「患者は実際に失効していた可能性が高い」と**申請者に有利な再構成**もしている。用量選択は最小有効用量 2.5 mg という正解だった——そして用量-毒性が単調であるがゆえに、用量は**レバーとして使えなかった**。

**試験遂行層。** 2010年以前の試験（1011・1014）はリスク低減措置なしで、CJSE が「過小検出・過小報告」とFDAに明記され審査から事実上除外された。承認審査は 2012年に規制が作らせた裁定装置（中央 MRI・委員会）通しの試験だけで構成された。公表の非対称もある: OA pivotal 3 本の専属論文は本稿で見ず、トップライン PR（2018-10-22）が先行した。

**規制層。** 2010-06 の hold は「非 OA では未記録」から始まり、2010-12 に非 OA でも関節破壊が見つかってクラス化し、2012年に条件付き解放、2015年に完全解除——**約4年9か月**。2021年の投票 1-19 は FDA の決定ではない。しかし会社は3か月後の 10-Q に「19:1 against vote」と記載し、市場に共有した。

**事業層。** 2006年買収→2013年疑義中の提携→2018-2020年の3地域申請→2021年10月、**提携相手と同じ月にグローバル中止**。日本（2020-08 提出）の席がどう畳まれたかは一次記録未取得＝**未確認**。

**致命的層はどれか。** 安全性層（不可逆な関節破壊）単独ではない。**安全性×入口設計（REMS）の積**が致命的層だ。投票が訊ねたのは「リスクがあるか」ではなく「**管理できるか**」で、FDA の答えは年次 X-ray・医療機関投与・NSAID カウンセリングの三要素すべてに対して個別に No だった。

## 5 四チームの視点 — 当時の手と、その反証条件

### 開発
**とりえた手:** 用量を上げる（効果は上がる——CJSE も上がる）。下げる（1.25 mg 級は審査に存在しない）。あるいは 1058 の run-in 設計（NSAID 反応者排除）を全試験に組んで「失効患者」を構造的に保証する。開発は実際には 2.5 mg・q8w を最小有効用量として選んだ。
**反証条件:** 用量-毒性が単調でなければ（例: 低用量で痛効果あり・RPOA 閾値下）、もっと低い用量で分離できただろう。2.5 mg の CJSE が placebo 比 2.4/100PY で**用量非依存に存在した**なら、この分子に用量の逃げ道は最初からなかった。次の観測点は、同クラスの低用量・短期間投与（例: 術後痛）で RPOA シグナルが消えるかだ（本稿で既知の進行試験なし）。

### 薬事
**とりえた手:** REMS を「検出装置」ではなく**曝露の停止規則**（例: 6 か月ごとの MRI で関節裂隙変化が出た時点で永久中止）として設計する。あるいは患者選別を重症度・体重・併用 NSAID で前方に絞り、適応を狭く刻む。FDA は提案 REMS の三要素を個別に否定した。
**反証条件:** RPOA2 が「中止でも止められない」以上、いかなる検出・停止規則も手遅れに間に合わない——これが FDA の論理だ。この論理が正しいかは、**検出後に進行が止まった症例群**（観察試験 NCT02674386 の結果）が観測できれば決着する。CRL の正確な日付・本文は**未確認**。

### メディカルアフェアーズ／学術公表
**とりえた手:** OA pivotal 3 本（1056/1057/1058）を、CLBP（Pain 2021） と等格で査読公表する。2018年の「non-opioid」PR は FDA に「オピオイドとの直接比較試験は存在しない」と反論されていた。
**反証条件:** OA pivotal の専属論文が本稿の検索範囲のどこかに存在するなら「公表の非対称」は崩れる。逆に存在しないまま PR のみが流通したなら、「非オピオイドの夢」は査読を経ない言説で市場を走ったことになる。次の観測点は DOI の有無。

### 事業
**とりえた手:** 2013年の提携（疑義中の買い増し）を疑う——hold 再係属・解除誤り（2013-08-28）のニュースが社内にあったはずだ。あるいは 2021-03 の 1-19 の後に**日本の席だけを守る**分離降板（日本は 2020-08 提出済み・日本 CLBP データあり）。
**反証条件:** 2013年提携は結果的に「6年半のグローバル開発の相乗り権」を買った。CRL がなければ（REMS が承認可能設計なら）リターンの大きい賭けだった。日本の席が本当に分離維持可能だったかは、PMDA が何を要求していたか（**未確認**）に依存する。

## 6 時代の環境 — 「非オピオイド」が規制文書に現れた年份

この分子の書類には、オピオイド危機が正確な日付で化石として残っている。2017-05-26 に Fast Track（ただし BTD は拒否）、**2017-10-02 に「乱用傾向検出されず、スケジュール指定不要見込み」**、2018-10-22 の会社 PR はこれを「**non-opioid treatment option**」として打ち出し、最終的な申請適応文には「（オピオイドについて）**服用を嫌がる**」患者が適応集団の文言として入った。審査中の FDA が申請者に示したリスク属性表には「Addiction and dependence／Overdose」が並んだ——tanezumab のリスクではなく、**比較対象（オピオイド）の**リスクとして。

同機序の行方は分かれた。fasinumab（Teva/Regeneron と報じる）や fulranumab は開発中止等で先に席を畳んだと報じられる。一方、**同じ抗 NGF 抗体が獣医療（犬の OA 痛）で承認されている**という通説は本稿で一次未取得（**未確認**）で、もし成立すれば「同機序・関節リスク議論あり・犬では承認・人では拒否」という本シリーズ最強の対照になる。同じ分子クラスが、種をまたいで生と死に分かれたのだから。

## 7 答えのない質問

本稿の目的は回答ではなく、決定点の復元である。以下に回答は書かない。

**Q1 とどめを刺したのは投票（REMS）か、CRL か、会社自身か。**
(a) 投票: 1-19 はREMS 設計への信任投票で、会社は3か月後の 10-Q に票決を記載し（「19:1 against vote」）、以後 REMS を作り直して再提出しなかった。(b) 会社自身: 死亡診断書の主語は「Pfizer and Lilly discontinued」で、動機は CRL＋CHMP——つまり規制文書が揃った月の**会社の能動行為**。(c) 否定（票決は決定でない）: 票決から CRL まで約6か月かかり、CRL が本体。FDA は元々「REMS で保証不可」と審査結論を持っていた。(d) 決着観測: **CRL の正確な日付と本文**（何が不足とされたか）。foia・会社開示。正確日付は。(e) 関連: 承認版 mdma（PDAC 2-9/1-10→CRL 65日）と flibanserin（10-1→再挑戦）。票決と決定の時間差を3件で比較できる。

**Q2 RPOA は薬の害か、それとも「効いてしまったこと」の害か。**
(a) 薬の害: CJSE は用量依存的で、**画像上健康な関節・非対象関節**にも発生し、動物データでもクラス・シグナルが出た。(b) 鎮痛の害: 痛くなくなった関節に体重と NSAID を載せる行為の帰結——実際、1058 では NSAID 併用で関節イベント 2〜3倍のシグナルがあり、REMS は NSAID カウンセリングをその仮説の実行手段にした。(c) 否定側の穴: RPOA2 では**中止しても止まらない**——「負荷だけであれば」除去後の停止で止まるはずだ。(d) 決着観測: 獣医療の抗 NGF 使用後の関節モニタリング報告（犬で同様の関節破壊が出るか）＝。人の長期観察 NCT02674386 の Results。(e) 関連: クロステーマ「クラスは一緒に死ぬ」。

**Q3 「有効性は実質証拠あり・しかし承認しない」は、規制として正しい裁定か。**
(a) 正しい: 閾値は benefit-risk にあり、2.5 mg は NSAIDs に優越せず、不可逆リスクを持つ——statistical efficacy ≠ approvability。(b) 過剰: 16週の共主要3項目を 2 試験で達成し、FDA は患者選抜の瑕疵を post-hoc に「実際は失効患者だっただろう」と救った。同じ審査資料で、患者志向データは「方法論的に unusable」と退けた。(c) 決着観測: 同等の効果量・同等の検出装置を持つ対照薬（NSAIDs 自体は RPOA を起こさないのか——1058 で tanezumab の方が HR 2.6-5.0 と**相対的に**悪かっただけの記述がある）。(d) 関連: 承認版 nalmefene（制限付き承認で入口を作る）との逆方向対照——**入口を作れなかった時に何が起きるか**。

**Q4 日本の席（2020-08 提出）はどう畳まれたか。**
(a) 分離生存の可能性: 日本は独自の CLBP 第3相（55施設・celecoxib 対照・関節安全イベント 1.1-2.2%）を持っていた。MDD 型地域分歧の伏線になりえた。(b) 同時死の側: Pfizer の開示は「グローバル中止」で、日本の取り下げ・継続の一次記録を見ず。(c) 決着観測: **PMDA の審査履歴（jRCT・審査報告書・取下げ届）**。本稿で取得不能。(d) 関連: zuranolone（米で死んだ MDD が日本で生まれた）——同じ分岐が tanezumab では起きなかった理由が本問。

## 8 教訓（開発者向け）

1. **有効性の実質証拠は承認の十分条件ではない。** FDA 自身が「substantial evidence を満たす」と書いた分子が、benefit-risk で死んだ。審査計画のゴールに「統計」ではなく「既存治療との差別化」を最初から置け。
2. **不可逆で無症候性に始まるリスクに、REMS は設計できない。** 検出（年次 X-ray）・管理（医療機関投与）・行動（NSAID カウンセリング）の三本柱は、それぞれが「間に合う」ことを前提にする。間に合わないリスクでは、入口設計というゲームに参加できない。
3. **用量-効果と用量-毒性が単調なとき、用量はレバーではない。** 2.5 mg は最小有効用量であり、かつ関節毒性は用量依存的だった。用量選択で逃げられない分子では、適応・併用・投与期間で逃げるしかない。
4. **「非オピオイド」は差別化ではない。** 比較試験（オピオイド対照）を持たないまま適応文に「服用を嫌がる」まで入れたとき、その物語は FDA の属性表では「Addiction and Overdose」という他者リスクとして記録された。
5. **共同開発では、死も共同である。** 2013年に一緒に賭けた二社は、2021年10月に同じ 10-Q の一語で一緒に降りた（「Pfizer and Lilly discontinued」）。地域で席を分けない提携は、地域での生存も分けられない。

### 6. 学術的論争

- **Placebo 対照の倫理（慢性痛）**: OA/CLBP で「既存薬失効患者をプラセボに置く」設計への批判（tanezumab 時期に「ethics of uncontrolled trials」型の論考ありとされる）→ **本稿で該当論文を特定できず **。決着観測: PubMed で Smith/Allen（Nat Rev Rheumatol 2017 級）の特定。
- **効果量の閾値**: FDA 再解析 -0.6/-0.5 点（WOMAC）を「modest」と明記。痛スケール MCID 論争に接続。
- **NMA（ネットワークメタ）でオピオイド比較を主張**: 申請者側 HTA 解析に対し FDA は「オピオイドとの直接比較試験は存在しない」と全面反論。
- CLBP 社説「balancing the risks and benefits」（Pain 2021）。

### 7. 「そのとき、そのチームは何を見ていたか」

- **開発（Pfizer、2010〜）**: hold 解除条件（5 mg 上限・裁定・中央 MRI）を**設計要件として内面化**し、2.5 mg を最小有効用量として申請した 。用量を上げれば効果は上がるが関節毒性も上がる単調曲線の中にいた [確定（用量依存 CJSE）]。
- **薬事（2019-12〜2021-03）**: 共主要が 52 週（1058）で壊れた状態で提出し、**REMS という「入口設計」で受益リスクを保証する戦略**を選んだ。FDA は X-ray 年 1 回・投与場の管理・NSAID カウンセリングの各要素を個別に否定した 。
- **メディカルアフェアーズ／学術**: OA pivotal 3 本の専属論文を（少なくとも本稿）見ず、トップライン PR（2018-10）が先行 。CLBP の Pain 2021 掲載・日本 CLBP の 2022 掲載＝**死後に論文が出てくる側** 。
- **事業（2013・2021）**: 2013 年に疑義中のクラスへ Lilly と賭け、2021-10 に**同じ提携相手と**同時に降りた。米/EU/日の 3 地域申請（〜2020-08）は「地域で席を分ける」前に世界的に死んだ 。

### C. 有効性（pre-specified vs post-hoc）— FDA 自身が「有効性の証拠は成立」と書いた分子

| 主張 | ラベル | メモ |
|---|---|---|
| FDA 結論表（高水準結論）: 「**Has tanezumab met the statutory requirement for substantial evidence of effectiveness?** → Two adequate and well-controlled studies demonstrate that **tanezumab 2.5 mg is superior to placebo** for OA pain」＝**統計の有効性は壊れていない** |  | 本編の核心。「効かない薬が落ちた」のではない |
| 「How does tanezumab compare to NSAIDs? → **2.5 mg is not superior** to prescription-strength **naproxen, celecoxib, or diclofenac** in patients who had demonstrably failed prior Rx-strength NSAIDs」 |  | 非オピオイドの約束は「NSAID より良い」ではなかった（Q1） |
| 効果量: Study 1056（16 週）WOMAC 痛 **LS 平均差 -0.6・p=0.013**。1057（24 週）**-0.5**。1058 は 2.5 mg 全滅 |  | WOMAC 痛スケール（0–20 換算）での小差。「modest treatment effect size at 2.5 mg, this would appear to be the **minimally effective dose**」 |
| 患者選抜（NSAID/opioid 失効歴）: 1056/1057 のスクリーニング文書は「**poorly documented**」だが post-hoc で「患者は実際に失効していた可能性が高い」と FDA 自身が結論（**申請者に有利な再構成**） |  | steelman 素材 |

### D. 安全性 — 決定点は RPOA（急速進行性 OA）に集約

| 主張 | ラベル | メモ |
|---|---|---|
| RPOA 定義: **Type 1**＝1 年で関節裂隙幅 **≥2 mm** 狭小／**Type 2**＝骨の喪失・破壊・崩壊。**CJSE**（複合関節安全イベント）で中央 MRI 読影＋裁定委員会により測定 |  | 2012 年以降の条件（後述）そのものが測定装置だった |
| CJSE 発生率（1056/1057）: placebo **0**、tanezumab 2.5 mg **2.4**、titration **0.6**、5 mg **4.6／100PY**。1058（NSAID 比）: 2.5 mg で **リスク差 2.4（1.0, 3.8）／10PY、HR 2.6（2.5 mg）・5.0（5 mg）**。**用量依存的** |  | 「placebo 0」が投票の地盤 |
| RPOA は**画像上健康な関節**（Kellgren-Lawrence grade 0-1）・非対象関節でも発生。→「鎮痛による負荷」仮説だけでは説明不能 |  | Q3 の一次根拠 |
| **RPOA1 からの 15%・RPOA2 からの 60% が TJR（関節全置換）へ**進行。**RPOA2 後に投薬中止しても進行は止まらない**（discontinuation ineffective） |  | **不可逆性**が REMS 敗北の論理的中心 |
| 神経系の害: mononeuropathy（手根管症候群最頻）・polyneuropathy。多くは軽度・自己限定。Neuropathy Impairment Score で監視 |  | 第 2 の重篤毒性だが投票の主因ではない |
| 2010-06 の停止時の公表像: 「OA 患者で病勢増悪・関節置換を要した少数例」「**非 OA 患者では記録されていない**」 |  | **6 か月後にこの前提が崩れる**（§E 2010-12-23） |

### F. REMS 設計の解剖（投票はこれに投じられた）

| 要素 | 申請者案 | FDA の反論 |
|---|---|---|
| 投与の場 | **2.5 mg SC q8w を医療機関で実施**（医療機関・薬局の certification） | RPOA は asymptomatic に始まる。投与の場を管理しても発生は防げない |
| モニタリング | **ベースライン＋年次の bilateral knee & hip X-ray** | 年次 X-ray の捕捉能力と、捕捉後に有効な介入が存在しない（RPOA2 では中止でも止められない） |
| 併用管理 | **NSAID 回避カウンセリング**（16 週 washout） | 現実の OA 患者は NSAID を使う。カウンセリングで上書きできるリスク設計ではない |
| 投票質問 | 「**Will the REMS proposed by the Applicant ensure that the benefits of tanezumab outweigh its risks?**」 | → **Yes 1 / No 19 / Abstain 0**（2021-03-25） |
