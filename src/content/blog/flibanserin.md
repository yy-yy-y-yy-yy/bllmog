# 有効性の主要評価項目で不成立となった薬は、なぜ10年後にREMSを解除して適応を拡大したのか

### ADDYI（フリバンセリン）— アルコール、REMS、諮問委員会を通じて「処方の入口」を作り替えた11年

*情報参照日: 2026-08-31。規制・試験・添付文書（ラベル）に関する記述は openFDA Drugs@FDA レコード、2015/2019/2021/2025年 ADDYI ラベル、2015年 承認レター、2015年 Summary Review、2025年 REMS supplement 承認レター、2025年 EFFICACY supplement 承認レターに基づく。商業実績・日本/EUにおける状況は本稿の一次資料では確認していない。医療行為の推奨を目的とするものではない。*

---

## 1. 2026年時点の「処方の入口」

2025年12月13日、FDA（米国食品医薬品局）は ADDYI の NDA 022526 に対する適応拡大補正申請（EFFICACY supplement S-013）を優先審査（priority）にて承認した。適応症は「獲得性・全般性低下性性欲障害（HSDD）を有する65歳未満の女性（women less than 65 years of age with acquired, generalized hypoactive sexual desire disorder）」へと拡大された。2015年の初回承認時が「閉経前女性」に限定されていたことを振り返ると、本剤は承認後10年余りで、**閉経状態（生殖ステータス）ではなく年齢によって処方対象を特定する医薬品**へと変化を遂げた。

さらに、その約10ヶ月前にはリスク評価・軽減戦略（REMS）が解除されている。2025年1月21日付の openFDA ステータスを有する S-012 REMS supplement では、服薬指導ガイド（Medication Guide）を REMS の構成要素から除外した上で、「Addyi に対する REMS はもはや不要である（a REMS is no longer required for Addyi）」と明記された。2015年に承認レターが連邦食品・医薬品・化粧品法（FD&C Act）505-1条に基づき、処方医および薬局に対する特別認証制度（ETASU）まで要求した厳格なリスク管理システムは、10年弱で「不要」と判断されるに至った。

現行ラベルには REMS Program も限定流通プログラム（restricted program）の記載も存在しない。しかし、黒枠警告（Boxed Warning）は維持されており、アルコール、中等度・強度の CYP3A4 阻害薬、および肝機能障害の併用・罹患に伴う重度低血圧・失神に対する警告は依然として残されている。また、患者向け服薬指導ガイド（Medication Guide）も Section 17 および患者向け添付文書として維持されている。

すなわち、ADDYI の現在地は「規制やリスク管理が完全に消失した薬」ではない。**REMS という重い運用管理装置を取り払い適応領域を拡大した一方で、安全性への警告を添付文書の最も目立つ最上部に据えたまま処方市場に存在する薬**である。本稿が追跡するのは、この状態へと至った11年間の軌跡である。

## 2. 最初の否定は、広告運動でも政治的圧力でもなかった

本剤の評価を決定づけた最初の転換点は、2010年の諮問委員会（Advisory Committee; AC）であった。FDA の 2015年 Summary Review によれば、「有効性のエビデンス（efficacy evidence）が十分か」との問いに対し、不十分と評価した委員は 10 対 1 に上った。また「ベネフィット/リスクプロファイルが許容可能か」という問いに対しては 11 対 0 の満場一致で否定（No）された。

不成立となったのは派手な事象ではなく、治験デザインの中核部分であった。Summary Review の記録によれば、当時の第3相2試験では電子日誌（daily electronic diary）で測定した性的欲求（sexual desire）を主要評価項目（co-primary endpoint）として設定していたが、この項目において統計的有意差を示すことができなかった。満足のいく性的事象（Satisfying Sexual Events; SSE）や FSFI Desire ドメインでは改善傾向が認められたものの、事前規定プロトコルからの逸脱として諮問委員会はこれを受け入れなかった。

この史実は重要である。後に ADDYI は「有効な治療薬が存在しない女性性機能障害の領域において、政治的運動や圧力によって強引に承認された」と語られがちである。しかし Summary Review が記録する最初の臨床的否定は、主要評価項目の検証に失敗したという至極科学的な評価に基づくものであった。

## 3. 2015年の承認は、desire 項目の検証失敗を内包したままスタートした

2015年8月18日、FDA は ADDYI を新薬承認した。適応は閉経前女性における獲得性・全般性 HSDD であった。

承認の根拠となったのは 3 つの 24 週間第3相試験であった。2015年版ラベルの Table 6 を確認すると、月間満足のいく性的事象（monthly SSE）は 3 試験すべてにおいてプラセボ群と比較して有意な改善を示していた。治療差（群間差）は Study 1 で 0.9（95% CI: 0.3, 1.4）、Study 2 で 0.6（95% CI: -0.03, 1.2）、Study 3 で 1.0（95% CI: 0.4, 1.5）であった。

課題となったのは性的欲求（sexual desire）側の評価である。Study 1 および Study 2 では電子日誌（eDiary）による daily desire を co-primary endpoint としていたが、群間差はそれぞれ 2.3（95% CI: -0.1, 4.7）、1.7（95% CI: -0.5, 4.0）であり、統計的有意差を得られなかった。一方、Study 3 では FSFI Desire ドメインを co-primary endpoint に変更し、群間差 0.3（95% CI: 0.2, 0.4、p < 0.0001）で有意差を達成した。

添付文書のデータが示すのは、承認臨床試験の中で「性的欲求（desire）」という同一の概念を異なる指標で測定しており、そのうち 2 試験で主要評価項目が不成立となったという構図である。承認後の「処方の入口」が極めて厳格化された背景には、この証拠構造（エビデンス・デザイン）の脆弱性が初期から埋め込まれていた点にある。

結果として承認の条件は、有効性の弱さを極めて厳格なリスク管理で補完する形をとった。2015年6月4日の合同諮問委員会では公開公聴会（open public hearing）が 1時間から 1時間45分へと延長され、「Even the Score」推進運動と申請企業との関係、およびジェンダーバイアス（性偏重）をめぐる意見が激しく交わされた。投票権を持つ委員 24名のうち、6名は限定的な有効性と安全性の懸念を理由に否決（reject）し、18名は添付文書外での厳格なリスク管理措置を条件として可決（accept）へ投票した。なお FDA は、ジェンダーバイアスに関する主張を承認判断の根拠とはせず、あくまで有効性（efficacy）と安全性（safety）のデータのみに基づいて判断したと明確に記載している。

## 4. アルコール相互作用が、本剤を「処方前に踏みとどまらせる薬」に変えた

2015年版ラベルの黒枠警告（Boxed Warning）には 3 点が並列して明記された。すなわち、アルコール、中等度/強度の CYP3A4 阻害薬、および肝機能障害である。いずれも重度の低血圧（severe hypotension）および失神（syncope）のリスクを著しく高めるためである。

承認レターにおいて FDA は、本剤の流通・処方にあたり REMS が不可欠であると指定した。その必須構成要素（ETASU）として処方医および薬局の特別認証制度が導入された。服薬指導ガイド（Medication Guide）や情報伝達計画（communication plan）のみではリスクを十分に軽減できないと判断されたためである。承認時ラベルには「ADDYI REMS Program」に基づく限定流通が規定され、処方医および薬局は事前の認証登録を受け、承認された流通チャネルのみを通じて薬剤を調剤・供給することが義務付けられた。

なぜこれほど厳格な管理体制が必要とされたのか。2015年版ラベルに記載された初期のアルコール相互作用試験がその根拠を示している。健康な被験者 25例に ADDYI とアルコールを併用投与した臨床試験において、エタノール 0.4 g/kg 併用群では 23例中 4例（17%）に医療的処置を要する低血圧・失神が発生した。さらにエタノール 0.8 g/kg 併用群では 24例中 6例（25%）に起立性低血圧（orthostatic hypotension）が認められた。

さらにフルコナゾール（fluconazole）併用試験では、2015年版ラベルによれば 15例中 3例（20%）で仰臥位（supine）での医療処置を要する低血圧・失神が発生し、うち 1例は意識消失および血圧 64/41 mmHg を呈して救急搬送および生化学的輸液処置を要する事態に至った。この併用によりフリバンセリンの血中暴露量（exposure）は約 7倍に増大していた。

本剤は、単に臨床的有効性が限定的であったから規制が厳しくなったのではない。**特定の併用条件下で急激な血圧低下を引き起こすという物理的な副作用プロファイル**こそが、REMS という「処方の入口を狭める」運用構造を生み出したのである。

## 5. REMS は、承認から 10年で「解除される装置」となった

2015年8月18日付の承認レターは、REMS の構成要素として処方医・薬局認証を要求すると同時に、承認後要求事項（PMR）2939-1〜2939-7 を課した。これには低血圧・失神・事故・致死的事象に対する強化ファーマコビジランス、虫垂炎に関する前向き観察研究、妊娠登録・母児転帰調査、ならびに対象女性集団におけるアルコール相互作用試験（ワーストケース・タイミング別・実地臨床試験）が含まれていた。

その後の openFDA 承認履歴には、複数の REMS 補正申請（REMS supplement）が記録されている。2016年、2017年、2019年に REMS 内容の変更が承認され、最終的に 2025年1月21日付の S-012 承認レターにおいて「REMS はもはや不要である（REMS is no longer required）」と明記されるに至った。

2019年10月9日のラベル改訂補正（LABELING supplement）により、添付文書の記載上からも本装置は除外された。2019年版ラベルの Recent Major Changes には、アルコール摂取の禁忌（contraindication）削除、および REMS Program セクションの削除（Removed）が明記されている。ただし REMS 制度自体は同日付の REMS supplement によって一度改訂（modification）されて継続しており、2025年のレターにおいて「直近の改訂承認は 2019年10月9日」と追及されている状態であった。2021年版ラベルにも REMS Program のセクションは存在せず、添付文書上においてはこの時点で同セクションは復活していない。

ここで生じた変化は、安全性の懸念が消滅したことを意味するものではない。2019年以降も黒枠警告（Boxed Warning）は維持されている。変更されたのはアルコール摂取に関する管理方法である。2019年版ラベルは、標準アルコール飲料（standard alcoholic drinks）1〜2 杯の摂取時は服用前少なくとも 2時間空けること、3杯以上の場合はその夜の服用を中止すること、服用後は翌朝までアルコール摂取を避けること、という具体的な行動指導へと置き換えられた。

つまり、2019年の規定改訂は「アルコールとの併用リスクが消えた」のではなく、**一律の絶対禁忌から、飲酒タイミングと摂取量の行動管理による運用制御へと転換した**と解釈するのが正確である。

## 6. 2019年の再評価は、アルコール試験の再検証に基づいていた

2019年版ラベルに記載された第2アルコール相互作用試験では、健康な閉経前女性 96例を対象として、朝方に ADDYI 100 mg と各種用量（0.2/0.4/0.6 g/kg）のアルコールを同時服用させた。その結果、失神や治療介入を要する低血圧は報告されなかった。一方で、嗜眠（somnolence）の発現率は ADDYI ＋ アルコール併用群で 81〜89%、めまい（dizziness）は 27〜40% に達し、アルコール単独群（それぞれ 25〜41%、6〜20%）と比較して顕著に高値を示した。

第3アルコール相互作用試験では、ADDYI 服用の 2/4/6時間前に 0.4 g/kg のアルコールを摂取させる条件が評価された。アルコール単独群で 1例の失神（syncope）が発生したほか、立位血圧測定不能となった症例が 3例認められ、その内訳はアルコール＋ADDYI 併用群で 2例、ADDYI 単独群で 1例であった。

これらの試験結果のみを考慮すると、2015年時点の「アルコール併用は一律禁忌」から 2019年の「時間と量を管理すれば投与可能」への移行は合理化されるように見える。しかしながら、第2試験においては、すでに低血圧やめまいを発症していた被験者に対して立位測定が禁止されたため、データ欠損や測定遅延が生じたという試験デザイン上の不確実性も残されている。すなわち、2015年に構築されたリスクの構図を、2019年の追加試験が完全に払拭したわけではない。

## 7. 2025年に残されたのは、REMS ではなく警告文書であった

2025年1月21日付の S-012 承認レターは、REMS の経緯を「2015年8月18日に初回承認、2019年10月9日に直近の改訂」と振り返った上で、服薬指導ガイド（Medication Guide）を REMS の構成要素から除外する判断を示した。FDA は、承認ラベルの一部として Medication Guide を維持すれば連邦規則集（21 CFR 208）の必要条件を満たすと結論付け、次のように明確に述べた。

> 「Addyi に対する REMS はもはや不要である（a REMS is no longer required for Addyi）」
> — NDA 022526/S-012 承認レター

同年、有効性の観点においても大きな適応拡大が行われた。2025年3月17日に受理（received）された S-013 適応拡大補正申請（EFFICACY supplement）により、適応症は「生殖ステータス（閉経状況）に関わらず 65歳未満の女性（women less than 65 years of age independent of reproductive status）」へと拡大された。

現行ラベルが根拠として挙げるのは Study 6（NCT00996372）である。自然閉経後かつ 65歳未満の女性を対象とした解析において、フル解析セット（FAS）は ADDYI 群 430例、プラセボ群 451例であり、主要評価項目である月間 SSE の変化量は ADDYI 群 0.9、プラセボ群 0.6、治療差 0.4（95% CI: -0.0, 0.8、p < 0.025）であった。また FSFI Desire ドメインの変化量は 0.7 対 0.4（治療差 0.3 [95% CI: 0.2, 0.5]、p < 0.0001）、FSDS-R 問13 は -0.8 対 -0.6（治療差 -0.2 [95% CI: -0.4, -0.1]、p < 0.01）であった。

得られた数値の構造は 2015年時の結果と酷似している。群間差は限定的であり、SSE の 95% 信頼区間は 0（効果なし）に接する境界上にある。そして性的欲求（desire）項目が再び評価の中心に位置している。しかし今回 FDA は、2015年のような「閉経前女性限定」ではなく、「閉経状態を問わない 65歳未満の女性」という新たな処方枠組みを承認したのである。

## 8. それでも「処方の入口」は、3 つの領域で厳格に維持されている

現行ラベルには REMS Program の記載はない。処方医や薬局の事前に認証登録という参入障壁は消滅した。しかし、残された制限規定は依然として 3 つ存在する。

第一に、適応対象は女性に限定されている。添付文書上において「男性への適応なし（not indicated in men）」および「性的パフォーマンス向上目的の適応なし（not indicated to enhance sexual performance）」の規定は厳格に維持されている。第二に、黒枠警告（Boxed Warning）は存在し続けている。服用前後の近接したアルコール摂取、中等度/強度の CYP3A4 阻害薬の併用、および肝機能障害における重度低血圧・失神のリスクは、依然として最も厳重な警告として最上部に掲示されている。第三に、日本人における薬物暴露量に関する注意喚起は米国添付文書内に維持されている。2015年版ラベルの Race/Ethnicity 項目では、健康な日本人女性におけるフリバンセリンの暴露量が白人女性と比較して約 1.4倍高いと記載されており、体重調整後の定常状態 AUC（AUCtau,ss）は日本人で 2,246 ng·h/mL、白人女性で 2,080 ng·h/mL であり、差の主な要因は人種（race）というよりも体重（weight）の違いによるものと示唆されている。

本剤の規制史は、単純な「規制緩和」の文脈のみで捉えることはできない。処方対象枠を拡大した年と、厳格な警告を維持した年が同一の添付文書上で重なり合っている。REMS という運用システムは消えたが、アルコールとの相互作用という物理的リスクは消失していない。適応は拡大されたが、男性および性的パフォーマンス向上目的での使用は依然として厳重に除外されている。

## 9. 商業的実態は本稿の一次資料からは記述できない

本剤が実際の医療現場でどれほど処方されたのか、売上高がいくらであったのか、また現在の実際の商業化主体が誰であるかについて、本稿が依拠した一次資料から確認することはできない。openFDA Drugs@FDA レコード上の sponsor of record は Sprout Pharmaceuticals, Inc. のままであるが、企業の所有構造や実質的な販売実績は規制データとは別の情報領域に属する。

したがって、検証可能な記事として誠実な記述形式は一律である。**「規制当局が処方の制限構造を変更した事実は追跡できるが、実際の処方数がどのように変動したかという商業的事実は追跡できない」**という位置付けである。商業データの欠落については「未解決の問い」として分類する。

## 9-5. 失敗／緊張の解剖（六層）

 §2-4。2010年に有効性で否定された分子が、入口設計（REMS）を作り替えて 2015 に承認、2025 に装置を外して適応を広げた。緊張の中心は**試験設計と規制（入口）**の層。

| 層 | この薬剤で起きたこと | 致命的? |
| :-- | :-- | :-- |
| **有効性** | 2010 AC で efficacy 不足 10対1。2015 承認時に desire（daily eDiary）は Study1 2.3・Study2 1.7 で非有意、Study3 FSFI desire 0.3 p<0.0001 のみ。SSE 治療差 0.6〜1.0 | **はい（設計と一体）** |
| **安全性** | 重度低血圧・失神。アルコール 0.4 g/kg で 4/23(17%)治療介入要。fluconazole 併用 3/15(20%)低血圧・失神（BP64/41）。日本人曝露1.4倍 | 入口を作った |
| **試験設計** | co-primary の desire を daily eDiary で測る設計が破れた | **はい** |
| **試験遂行** | アルコール相互作用試験を2度（2015 禁忌→2019 第2試験 n=96 で syncope/低血圧なし） | 中間 |
| **規制** | REMS ETASU(2015)→ alcohol contraindication Removed(2019)→ REMS Removed(2025)→ 適応拡大(<65歳)。2015 AC 18 accept / 6 reject。FDA Summary Review は gender bias を承認根拠に使わず efficacy/safety と明記 | **はい** |
| **事業** | 売上・処方量・現在の商品化主体は一次取得不能。日本/EU 承認未確認 | 判定不能 |

**致命的層＝設計（co-primary desire を eDiary で測った選択）×規制（入口を REMS で作り、2025 に作り替えた）**。

## 9-6. 四チームの視点（当時の手と反証条件）

- **開発**：desire を何で測るか（daily eDiary vs FSFI）が承認まで5年超を決めた（反証：測り方を変えれば co-primary は成立した）。
- **薬事**：REMS ETASU を入口に置く→解除する、という入口設計の長期戦略（反証：REMS 解除後に benefit>risk が後退する）。
- **メディカルアフェアーズ**：gender bias 論争（Even the Score）と FDA の否定を一次で分けて書く。委員会の票決＝FDA の決定ではない。
- **事業**：商業実績・商品化主体は一次取得できない限り主張しない（2025 の適応拡大が商業に転換されたかは別データ）。

## 9-7. 答えのない質問

1. **2015年の承認は有効性で開いたのか社会的圧力で開いたのか。** (a)圧力説：AC 公開聴聞・Even the Score。(b)有効性説：FDA Summary Review が gender bias を承認根拠に用いていない明記＋2025 Study6 の efficacy。(c)決着観測＝2025 Study6 申請書全文。(d)接続＝mdma（委員会≠当局・社会的圧力）。
2. **REMS 解除は benefit>risk の後退か、エビデンス成熟か。** 決着観測＝解除後の低血圧・失神報告（未取得）。
3. **「閉経状態」から「年齢」への入口の書き換えは緩めたのか締めたのか。** 決着観測＝<65歳・生殖ステータス別群の有害事象。
4. **規制の成功は商業の成功に転化したか。** 決着観測＝売上・処方量・商品化主体（一次取得不能＝本稿の最重要保留）。

## 9-8. 教訓（開発者向け）

1. co-primary endpoint は「有効性の中心」そのもの。desire を daily eDiary で測る設計が破れると、承認まで5年以上の規制史になる。
2. REMS は処方の入口を作るが、永遠の傷痕ではない。2015に必須とされた装置は2025に不要とされた。
3. ラベルの警告と運用装置は別々に消える。REMS Program は消えても Boxed Warning と Medication Guide は残った。
4. 適応拡大は「閉経状態」から「年齢」へ入口を書き換える。2025年の ADDYI は生殖ステータスを問わない65歳未満女性の薬になった。
5. 規制の成功と商業の成功は別のデータで測る。売上・処方量・商品化主体は一次取得できない限り記事で主張しない。

## 10. 何が確定し、何が未解明であるか

ADDYI に関する一次資料から客観的に確定できる事象は、以下の時系列に従う。

1. **2010年**の諮問委員会（AC）は、電子日誌による daily desire の主要評価項目（co-primary）不成立を理由に、有効性（efficacy）を否定した。
2. **2015年**の承認は、月間 SSE の改善と性的欲求（desire）項目のデータの不確実性を抱えたまま、アルコール相互作用と REMS の設置を条件として与えられた。
3. **2019年**にはアルコール併用の絶対禁忌が添付文書から削除され、摂取タイミングと飲酒量に基づく行動管理へと変更された。
4. **2025年**には REMS が不要と判断されて解除され、同年に適応症は 65歳未満の女性（閉経状態を問わない）へと拡大された。
5. **それでもなお**、黒枠警告（Boxed Warning）、男性の除外、および性的パフォーマンス向上目的の除外規定は厳格に維持されている。

一方で、一次資料からは確定できていない事項として、2019年改訂時の内部意思決定根拠、PMR 2939-1〜7 の最終報告結果、2025年適応拡大試験の申請書全文および臨床審査報告書（Clinical Review）、政治的要請や「Even the Score」キャンペーンの資金関係、日本および EU での承認状況、ならびに実際の販売実績が挙げられる。これらは「社会的に言及されやすいが、本稿では採用しない」情報として未解決事項へ分離する。

本剤の 11年間にわたる軌跡を総括するならば、次のようになる。有効性の主要評価項目が不成立となった医薬品は、有効性の決定的なエビデンスを新しく獲得したのではなく、**リスク管理の構造を自ら再構築し続けることによって、「処方される場所（入口）」そのものを変容させてきた**のである。

### 2. 追い風・向かい風の総括的分析

- **最大の追い風となったのは、規制当局（FDA）による「女性性機能障害は未充足ニーズが高い疾患領域である」という公式見解の表明であった**
 2014年の患者参加型集会（Patient-Focused Meeting）および 2015年の諮問委員会（AC）における公開公聴会は、患者の疾患負担と治療選択肢の不足を公的に可視化した。ただし FDA は、推進運動側が主張したジェンダーバイアス（性偏重）そのものを承認の直接的根拠とはしておらず、新薬審査部門長（Division Director）は「そうした主張は承認判断の根拠として用いない」と審査文書に明確に記録している。

- **最大の障害（向かい風）となったのは、臨床的有効性そのものの実証不全であった**
 2010年の諮問委員会（AC）が承認を拒否した主因は、社会的な運動や広告ではなく、電子日誌（daily eDiary）による sexual desire（性的欲求）という事前規定された主要評価項目（co-primary endpoint）の検証失敗であった。2015年の承認時においても、満足のいく性的事象（SSE）は全試験で有意な改善を示したものの、欲求（desire）項目は試験ごとに評価尺度が変遷し、第3相臨床試験 1 および 2 では主要評価項目の達成に失敗していた。

- **二番目の障害（向かい風）は、アルコール相互作用および中枢神経（CNS）抑制に伴う安全性プロファイルであった**
 初期のアルコール相互作用試験では、被験者 25例（男性 23例、閉経前女性 2例）において重度の低血圧・失神が発生し、医療的介入が必要とされる事例が相次いだ。これに CYP3A4 阻害薬および肝機能障害に伴う血中薬物濃度の急激な上昇（Exposure の増大）が重なったことで、2015年の初回承認時には「アルコールの絶対禁忌」と「特別認証制度（ETASU）を伴う厳格な REMS」の設置が義務付けられた。

- **規制の方向性は、2019年から 2025年にかけて緩和・合理化へ明確にシフトした**
 2019年には添付文書からアルコールの絶対禁忌が削除されて時間管理・量管理の行動指導へと変更され、2025年には REMS という重い運用管理システム自体が不要と判断されて解除された。同時に適応症は「閉経前女性限定」から「65歳未満女性（閉経状況不問）」へと拡大した。すなわち本剤の 10年余りの軌跡は、「承認後に規制が強まった医薬品」ではなく、**「市販後の安全性データ積み上げと運用実績に基づき、処方の入口を段階的に広げてきた医薬品」**として捉えるのが客観的に正確である。

- **それでもなお解除されず残された規制枠組みは 3 点存在する**
 ① 適応対象は女性のみに制限されていること、② 男性への投与および性的パフォーマンス向上目的での使用は明示的に禁止されていること、③ 服用前後のアルコール摂取、CYP3A4 阻害薬の併用、および肝機能障害に伴う重度低血圧・失神に対する注意喚起は依然として最も厳重な「黒枠警告（Boxed Warning）」として最上部に掲載されていること、である。運用上の規制負担が消滅した部分と、危険性の警告が消滅しない部分との構造的落差こそが、現在の ADDYI の規制上の位置付けを正確に規定している。

### E. REMS の生成と解消

| 主張 | ラベル | メモ |
|---|---|---|
| 2015年承認レターにおいて、FDA は連邦食品・医薬品・化粧品法（FD&C Act）505-1条に基づき、アルコール相互作用による重度低血圧・失神のリスクを軽減するためリスク評価・軽減戦略（REMS）が必要と判断した |  | REMS Requirements |
| 2015年指定の REMS では、処方医（prescriber）および薬局（pharmacy）の特別認証を必須要素（ETASU）として要求。服薬指導ガイド（Medication Guide）や情報伝達計画（communication plan）のみではリスクを十分に軽減できないと明記された |  | Elements to assure safe use |
| 2015年承認時ラベルは「ADDYI REMS Program」に基づく限定流通を指定。処方医・薬局の認証登録、患者への説明、認定薬局への限定等を要求した |  | 5.2 |
| 2015年承認レターは承認後要求事項（PMR 2939-1〜2939-7）を定めた。2939-1 は低血圧・失神・事故・致死的事象の強化ファーマコビジランス、2939-2 は虫垂炎の前向き観察研究、2939-3 は妊娠登録、2939-4 は母児転帰調査、2939-5〜7 は対象女性集団におけるアルコールのワーストケース試験・タイミング別試験・実地臨床試験である |  | PMR 記載 |
| 2019年改訂ラベルの Recent Major Changes に「REMS Program (5.2) 削除」が明記された。ただし REMS 制度自体はその後 2019-10-09 に一度改訂（modification）を経て継続された |  | 2019 label / 2025 letter の REMS 履歴 |
| 2021年改訂ラベルにおいても REMS Program セクションの記載はない |  | Recent Major Changes / Section 5 |
| 2025年の REMS 補正申請（supplement S-012）は 2024-07-23 に日付設定・受理され、openFDA 上で 2025-01-21 に承認（AP）された |  | S-012 |
| 2025年承認レターは REMS の経緯を「2015年8月18日に初回承認、直近の改訂は 2019年10月9日承認」と記載。当時の REMS は Medication Guide と評価タイムテーブルのみで構成されていた |  | REMS Requirements |
| 2025年承認レターは Medication Guide を REMS の構成要素から除外。承認ラベルの一部として Medication Guide を維持すれば 21 CFR 208 の規定を満たすと判断し、「Addyi に対する REMS はもはや不要である（a REMS is no longer required for Addyi）」と明記した |  | REMS Requirements |
| 2025年現行ラベルには REMS や限定流通プログラムの文言はないが、患者向け Medication Guide およびアルコール併用・中枢神経（CNS）抑制に関する服薬指導（counseling）は維持されている |  | Section 17 と Medication Guide |
